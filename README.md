# extrasforge
Governed media ingestion on Amazon Bedrock Data Automation, a tenant of [agentkeel](https://github.com/andaro74/agentkeel). BDA describes the media; extrasforge decides which descriptions can be indexed as fact — by a rule a seat owns, not by a prompt — and proves it with ten planted errors the gate must catch. One runtime agent (Strands on AgentCore) assembles an extras package from a prompt with a citation on every asset and nothing outside the caller's title grant. Built milestone by milestone with Claude Code: one claim, one planted failure, one measured verdict each. Fictional slate; CC-BY stand-in footage.
