# extrasforge — file structure (rev 2)

Every path lists the PR that creates it and the seat that owns it. A
path on `main` before its PR is a path no seat has authorised. Folders
are not created empty.

## What changed in rev 2

| Path | Change |
|---|---|
| `infra/gateway/inference-targets.yaml` | new; the single provider-model mapping; Threshold Owner; two-key |
| `infra/gateway/gateway.*` | new; one Gateway with MCP targets and an inference target; Security |
| `src/gateway/interceptors/` | new; request and response Lambdas; Security |
| `agents/search-media/manifest.yaml` | carries `model_alias`; a provider model id here fails `validate` (R13) |
| `thresholds.yaml` | gains `daily_usd_per_user` at M06 |
| `docs/adr/ADR-0007-inference-target.md` | records the departure from agentkeel's LLM-gateway alias |
| `.github/workflows/cost-cap.yml` | reads the interceptor ledger from M06 |
| `tests/gateway/test_interceptors.py` | new at M06 |

Nothing before M06 changes. The control, the fixtures, the rulebook and
the calibration are model-path agnostic by construction.

| Path | Seat |
|---|---|
| `SPEC/`, `milestones/`, `docs/`, `CLAUDE.md`, `.claude/skills/`, `README.md`, `LICENSE`, `NOTICE` | Product |

| `src/` (but interceptors), `scripts/`, `tests/`, `Makefile`, root config, `agents/<n>/` remainder, `evals/history/` (CI only), `evals/local/` | Engineering |
| `.claude/agents/<n>.md` | the seat in its front matter |
